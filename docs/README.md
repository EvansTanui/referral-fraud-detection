# Referral Fraud Detection – Data Engineering Project

## Project Overview
This project analyzes referral program data to detect potential fraud patterns
using rule-based data signals. The goal is to identify suspicious referral behavior
that may indicate abuse of incentives or system loopholes.

## Dataset
The analysis uses the following datasets:
- user_referrals.csv
- user_referral_logs.csv
- paid_transactions.csv
- referral_rewards.csv
- user_logs.csv

## Fraud Detection Logic

### 1. Self-Referrals
Detects cases where a user refers themselves by checking whether
`referrer_id` is equal to `referee_id`. This can indicate attempts to
illegitimately benefit from referral incentives.

### 2. High-Volume Referrers
Identifies users who generate an unusually high number of referrals.
This behavior may indicate referral farming, automation, or coordinated abuse.

### 3. Referrals Without Completed Transactions
Flags referrals that never result in a completed payment transaction.
This may indicate abuse of referral rewards or incomplete / invalid conversions.
